## 找到並修掉的真實問題(都是乾淨沙箱測試抓不到的)
1. **首頁空白/很慢**:真實資料下 `/api/analytics` 要 7 秒、用量/活動各 1.7 秒,且是同步運算,卡住整個 server;前端又用 `Promise.all` 綁住所有 API。→ 重運算改到 worker thread(`tools/heavy-worker.mjs`)+ stale-while-revalidate 快取;前端拆成 `loadCore`(看板/專案,快)與 `loadHeavy`(用量/活動/額度/分析,各自獨立)。
2. **舊式 `review` 狀態被標成「待核准計畫」**(假警報)→ 改標「已完成・待你驗收」。
3. **Codex 額度卡版面擠壞**、**活動動態被 PowerShell 指令原文洗版**、**Detail 時間軸顯示原始 epoch 與 JSON** → 修 CSS、截斷/清理文字、格式化時間。
4. **用量頁與首頁「今日」口徑不同卻沒說明** → 標明「看板派工」口徑。
5. **agy 用量永遠「無資料」**:解析器認 `type/kind:'result'`,真實輸出是 `{"event":"result"}`(合成 fixture 測不到)→ 修並改用真實樣本測試。
6. **codex/claude 任務用量「無資料」**(時間窗估算對不上)→ 改讀 run 的 raw log(`turn.completed`/`result` 事件)的準確用量。
7. **需求拆解 UI 實際是壞的**:依賴欄位空字串被 `Number('')===0` 解讀成「依賴第 0 張」→ 第 1 張自我依賴、其他張被悄悄加錯誤依賴,確認建立一律失敗。→ `parseDepsInput` + 單元測試 + e2e。
8. **agy 沒有指令權限時**只看到難懂的「沒有產生回覆文字」→ 改為 needs-you(permission)並告訴使用者執行 `node tools/agy-permissions.mjs on`。
9. 提交時曾因 `;` 串接而把測試失敗的程式 commit 出去(靜態掃描);立刻補修,之後改用 `/tmp/gate.sh`(單元+e2e 全過才 commit)。
